# ExpBotl

Мод для **Minecraft 1.21.11 + Fabric**, который делает использование бутылочек опыта быстрым и удобным.

## Что делает

| Действие | Поведение |
|---|---|
| **ПКМ** (обычный клик) | Всё как в ванилле — бросается одна бутылочка |
| **Shift + ПКМ** | **Весь стак** бутылочек используется мгновенно, и вы сразу получаете весь опыт |

При Shift+ПКМ мод:

1. Берёт **весь стак** в руке — сколько бы там ни было (не 64, а столько, сколько реально лежит: работает и со стаками по 1024 с модованных серверов);
2. Для каждой бутылочки просчитывает опыт **ровно по формуле ваниллы 1.21.11**: `3 + random(0..4) + random(0..4)` — то есть от 3 до 11 с средним ~7 (орб опыта при разбитии бутылочки выпадает именно так);
3. Суммирует всё и **мгновенно выдаёт игроку** — без сфер опыта, физики и задержки на подбор, что важно при больших количествах;
4. Проигрывает звук разбития бутылочки, «плинк» опыта и зелёные искры, чтобы было видно, что действие сработало.

Пример: стак из 1024 бутылочек → примерно **7168 опыта** (1024 × ~7) за один клик, вычисление занимает микросекунды.

## Оптимизация

«В лоб» для каждой бутылочки нужно два вызова генератора случайных чисел (`nextInt(5)` + `nextInt(5)`) — 2048 вызовов для стака из 1024 штук.

ExpBotl бросает сразу **6 бутылочек (12 «кубиков») за один вызов RNG**: одно равномерно случайное число из `[0, 5¹²)` кодирует 12 независимых цифр в пятеричной системе — это взаимно-однозначное соответствие, поэтому **распределение математически идентично** поочерёдному броску каждой бутылочки. Итого ~187 вызовов вместо 2048 — примерно **в 11 раз меньше** нагрузки на RNG (само по себе это и так микросекунды, но при частом использовании на многолюдном сервере каждая мелочь на счету).

## Установка

1. Установите [Fabric Loader](https://fabricmc.net/use/) ≥ 0.16.9 (собрано и проверено на 0.19.x — подойдёт и ваша 0.19.3) для Minecraft **1.21.11**;
2. Положите `expbotl-<версия>.jar` из [корня репозитория](.) в папку `mods`:
   - **Клиент и сервер** — идеальный вариант: чистое поведение без лишнего звука броска;
   - **Только сервер** — тоже полностью работает (опыт и расход стака приходят с сервера), но ванильный клиент успеет проиграть звук броска одной бутылочки.

**Fabric API не требуется** — моду нужен только Fabric Loader. В креативе стак не расходуется, но опыт всё равно выдаётся.

## Как это работает (технически)

Один Mixin: `ItemStackMixin` перехватывает `ItemStack.use(...)` — точку входа любого использования предмета, через которую ванильный `ExperienceBottleItem.use` вызывается и на клиенте, и на сервере. Если предмет — бутылочка опыта и игрок присуд:

- вычисляется суммарный опыт (`ExperienceRoller`, формула идентична ванильной);
- опыт выдаётся напрямую через `PlayerEntity.addExperience(...)` (синхронизация полоски опыта — штатная, через тик игрока);
- стак уменьшается на всё количество через `decrementUnlessCreative` (в креативе не тратится);
- возвращается `SUCCESS` с новым содержимым руки — ровно тот же контракт, что у ванильного броска бутылочки, поэтому свинг руки, статистика «предметов использовано» и синхронизация слота с клиентом работают штатно.

Обычный ПКМ не затрагивается вовсе — мод включается только при приседании.

## Сборка из исходников

```bash
./gradlew build
# готовый jar появится в build/libs/
```

Требуется JDK 21+. Сборка автоматически проверяется в GitHub Actions: мод компилируется, собранный jar проверяется на ремап в intermediary-имена (пригодность для продакшена), и с модом поднимается dev-сервер (smoke-тест, mixin применяется без ошибок).
