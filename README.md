# ExpBotl

Мод для **Minecraft 1.21.11 + Fabric**, который делает использование бутылочек опыта быстрым и удобным.

## Что делает

| Действие | Поведение |
|---|---|
| **ПКМ** (обычный клик) | Всё как в ванилле — бросается одна бутылочка |
| **Shift + ПКМ** | **Весь стак** бутылочек используется мгновенно, и вы сразу получаете весь опыт |

При Shift+ПКМ мод:

1. Берёт **весь стак** в руке (не 64, а сколько есть — работает и со стаками по 1024 с модованных серверов);
2. Для каждой бутылочки просчитывает опыт ровно как в ванилле — **случайное число от 3 до 11** (в среднем ~7);
3. Суммирует всё и **мгновенно выдаёт игроку** (без сфер опыта и задержки на подбор — меньше нагрузки на сервер при больших количествах);
4. Проигрывает звук и зелёные искры, чтобы было понятно, что действие сработало.

Пример: стак из 1024 бутылочек → примерно **7168 опыта** (1024 × ~7), вся операция занимает микросекунды.

## Оптимизация

В ванилле каждая брошенная бутылочка даёт `random.nextInt(9) + 3` опыта. Для 1024 бутылочек «в лоб» понадобился бы 1021+ вызов генератора случайных чисел.

ExpBotl бросает сразу **6 бутылочек за один вызов RNG**: одно равномерно случайное число из `[0, 9⁶)` кодирует 6 независимых цифр в девятеричной системе (взаимно-однозначное соответствие). Распределение получается **математически идентичным** поочерёдному броску каждой бутылочки, а генератор случайных чисел нагружается в ~6 раз меньше: 1024 бутылки → всего ~171 вызов вместо 1024.

## Установка

1. Установите [Fabric Loader](https://fabricmc.net/use/) ≥ 0.16.9 (собиралось под 0.19.x — работает на 0.19.3 и новее) для Minecraft **1.21.11**;
2. Положите `expbotl-<версия>.jar` из [корня репозитория](.) в папку `mods`:
   - **Клиент и сервер** — идеальный вариант: никакого звука броска на клиенте, всё чисто;
   - **Только сервер** — тоже работает, но клиент проиграет звук броска (сама бутылка не полетит).

Fabric API **не требуется** — моду нужен только Fabric Loader.

## Как это работает (технически)

Один Mixin: `ItemStackMixin` перехватывает `ItemStack.use(...)` (точка входа любого использования предмета, вызывается и на клиенте, и на сервере). Если предмет — бутылочка опыта и игрок присел — вычисляется суммарный опыт (`ExperienceRoller`), выдаётся через `PlayerEntity.addExperience(...)`, стак уменьшается на всё количество (`decrementUnlessCreative` — в креативе не расходуется), и ванильный бросок отменяется. Обычный ПКМ не затрагивается вовсе.

## Сборка из исходников

```bash
./gradlew build
# готовый jar появится в build/libs/
```

Требуется JDK 21+ (сборка проверяется в CI через GitHub Actions).
